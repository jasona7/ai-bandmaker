## Adversarial spot-checks — fresh numerical contrast verifications

I deliberately rotated angles. Yesterday's spot-checks were qualitative (bg-dot occlusion, encodeURIComponent edge cases, title injection). Today's are **numerical** — I recomputed WCAG 1.4.3 ratios for surfaces the prior logs claim "pass" but never showed the math.

All ratios computed via the standard sRGB-to-linear transform (channel ≤ 0.04045 → channel/12.92; else → ((channel+0.055)/1.055)^2.4), then L = 0.2126·R + 0.7152·G + 0.0722·B, then ratio = (L_lighter + 0.05) / (L_darker + 0.05).

1. **`a:visited` `#cc99ff` on body `#000022`** — L_text ≈ 0.4486, L_bg ≈ 0.00171; ratio **≈ 9.65 : 1**. AAA pass (≥ 7).
2. **`.banner-tagline` `#ff69b4` on banner gradient (worst stop `#000099`)** — L_text ≈ 0.3406, L_bg ≈ 0.01835; ratio **≈ 5.72 : 1**. AA pass for normal text (≥ 4.5); below AAA. Acceptable, AAA not targeted.
3. **`.retro-button` `#00ffff` on `#333366` (default)** — L_text ≈ 0.7874, L_bg ≈ 0.0419; ratio **≈ 9.11 : 1**. AAA pass.
4. **`.retro-button:hover` `#ffff00` on `#444488`** — L_text ≈ 0.9278, L_bg ≈ 0.0594; ratio **≈ 8.95 : 1**. AAA pass.
5. **`.gallery-row:hover` `#00ffff` link on `#111133`** — L_text ≈ 0.7874, L_bg ≈ 0.00866; ratio **≈ 14.3 : 1**. AAA pass.
6. **`.feature-box p` `#aaaaaa` on `#0a0a2a`** — L_text ≈ 0.4019, L_bg ≈ 0.00417; ratio **≈ 8.34 : 1**. AAA pass.
7. **`.footer-copy` `#9999bb` on body `#000022`** — L_text ≈ 0.3291, L_bg ≈ 0.00171; ratio **≈ 7.33 : 1**. AAA pass.

The only borderline-AA surface in the entire palette I have now computed end-to-end is the banner tagline at 5.72:1 — comfortably above the 4.5 AA threshold for normal text (and the tagline is 0.9 × 14px ≈ 12.6px, so it's normal text, not "large" with the looser 3:1 threshold). No new finding.

Jinja conditional emits `aria-current="page"` on the active nav link by comparing `request.endpoint`. Correct WAI-ARIA usage (the literal `"page"` token, not `"true"`). Pass.

## Spot-check 9: `errorDisplay` redundant `role="alert"` + `aria-live="assertive"`

`generate.html:109`: `role="alert"` implicitly sets `aria-live="assertive" aria-atomic="true"`. The explicit duplicate `aria-live="assertive"` is **allowed by spec** (WAI-ARIA 1.2 §6.6.1 — explicit attribute reinforces, does not conflict). Some older AT have been observed to double-announce when both are present, but contemporary NVDA/JAWS/VoiceOver versions de-duplicate. Not a finding.

## Spot-check 10: `<img>` width/height attributes (CLS concern)

`gallery.html:24` `<img>` has no explicit `width`/`height` HTML attributes; size is set via CSS `.gallery-thumb { width: 90px; height: 90px; }`. Modern browsers (Chrome 88+, Firefox 71+) compute the aspect ratio from CSS for CLS purposes, so this is no longer a meaningful layout-shift risk on supported browsers. Not a WCAG violation either way — purely a Core Web Vitals performance polish item. Not a finding.

## Spot-check 11: Mobile `.retro-button-small` AA touch-target

`min-height: 32px` (`style.css:311`) plus `padding: 8px 16px` brings the rendered hit area to ~32×~56px. WCAG 2.5.8 AA is 24×24, so this passes AA with margin; AAA (44×44) would require an extra ~12px vertical, but the project targets AA. Pass.

## Spot-check 12: `<noscript>` fallback on `/generate`

`generate.html:14–30` displays the Start UI server-side, including the `<button id="generateBtn">`. Without JS the button does nothing — the page degrades to a non-functional but non-broken state (no spinner stuck in motion, no fake progress). Logged as N17 LOW deferred; severity stays LOW because the failure mode is silent rather than misleading. Not promoted.
